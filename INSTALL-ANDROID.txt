ATLAS Estimating v2.9.2 — Android fullscreen update

1. In ATLAS, use OPTIONS > Download Project Backup for each important job before updating.
2. Upload the CONTENTS of this entire Android-only folder to the existing Android repository. Do not mix files with the iPad Tape Layout project.
3. Open android.html in Android Chrome over HTTPS while online; reload once.
4. Close the installed ATLAS app fully, then reopen to load the new offline cache.
5. Tap VIEW > FULL SCREEN (or the fullscreen button) to enter real browser fullscreen on supported Android/desktop browsers.
6. Tap Exit Full Screen or use the browser's ESC control to leave.

When the browser denies native fullscreen, the program still offers its previous page-filling viewer.
The fix changes only fullscreen handling and the Android cache version. Existing tape, ceiling, wall, dark/light, and PDF functions remain in the package.
