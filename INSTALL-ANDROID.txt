ATLAS Estimating v3.0 — CABINET BLOCKING ELEVATION (ANDROID)

ATLAS Estimating v2.9.2 — Android fullscreen update

1. In ATLAS, use OPTIONS > Download Project Backup for each important job before updating.
2. Upload the CONTENTS of this entire Android-only folder to the existing Android repository. Do not mix files with the iPad Tape Layout project.
3. Open android.html in Android Chrome over HTTPS while online; reload once.
4. Close the installed ATLAS app fully, then reopen to load the new offline cache.
5. Tap VIEW > FULL SCREEN (or the fullscreen button) to enter real browser fullscreen on supported Android/desktop browsers.
6. Tap Exit Full Screen or use the browser's ESC control to leave.

When the browser denies native fullscreen, the program still offers its previous page-filling viewer.
The fix changes only fullscreen handling and the Android cache version. Existing tape, ceiling, wall, dark/light, and PDF functions remain in the package.

V2.9.3 CHANGE: Saved ceiling badges now show NUMBER over calculated AREA SF.

V2.9.4: Open VIEW > SCROLL ON (or full-screen SCROLL). Mouse wheel/trackpad now pans the plan; use Ctrl+wheel/pinch to zoom. On Android, use finger drag or the directional scroll pad. SCROLL OFF returns to normal markups.


NEW: Select and save a wall, then open BLOCKING ELEVATION. Wood blocking is installed between studs, with drag, resize, dimension input, cut-piece estimates, saved project backups and PDF material reports. Upload blocking-editor.js with all other files. See README-BLOCKING-v3.0.md.

V3.1 UPDATE — Blocking elevation field dimensions:
- In BLOCKING ELEVATION, choose feet or inches and a Bottom/Center/Top AFF reference.
- Press TAP START → END, tap the starting position/height, then tap the ending position.
- Selected blocking displays length, left offset, and vertical AFF from finished floor.
- For details read README-BLOCKING-v3.2.md.

V3.2: Blocking dimensions display only when you tap a blocking row on the elevation or in the markup list. Tap again (or empty space) to hide.
