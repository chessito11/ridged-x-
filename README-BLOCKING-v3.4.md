# ATLAS v3.4 — Green Blocking Indicators

The Blocking button in the wall takeoff/markup table appears GREEN when that wall has one or more saved blocking runs. The button shows a run count: `Blocking (2)` means two saved runs. Walls with no saved blocking retain the standard button color. The indicator refreshes with the wall takeoff list when blocking is saved or removed.

No changes were made to blocking geometry, PDF exports, saved project format, material quantities, doors, or ceiling features.
