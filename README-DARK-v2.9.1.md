# ATLAS Estimating v2.9.1 — Drawing Dark / Light Switch

This Android update is built directly on v2.9 (TAPE), retaining ACT/Rigid X takeoffs, purple drywall + light hatch, large hanger-wire dots, PDF reports and all existing measuring tools.

## Using the new control

- **DARK ON** in the top toolbar means the drawing has its original near-black background.
- Tap **DARK ON** to switch to **DARK OFF**: the DXF drawing changes to a near-white background with readable dark original linework and adjusted framing/grid colors.
- Tap again to restore the dark background.
- The same button is in full-screen mode.
- The setting is remembered locally in the current browser/device, even after reopening the app. It applies to the drawing viewer only, not the menu panels.
- The switch is display-only; it doesn't change calibration, tape distance, ceiling grid layout, wall takeoff quantities, or saved-project data.

## Installing on Android

Back up saved projects; replace the **complete** published Android folder with these files. Open `android.html` over HTTPS in Chrome while online, refresh once, fully close the installed app, and reopen. The service worker cache name was increased to get the updated files. Use project backup/restore for transferring projects to another device.
